# Sidekick Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows desktop companion that turns the Ray-Ban Meta glasses (a plain Bluetooth headset under Windows) into an audio interface for Claude Code: hear when Claude is done or needs input, answer by voice, ask side questions by touchpad gesture.

**Architecture:** Python sidecar (FastAPI, port 47821) owns all state, audio, Bluetooth, gestures, STT/TTS and the Claude integration (Agent SDK for the embedded session and for cheap utility calls; HTTP hooks for external terminal sessions). Tauri 2 shell hosts a Vue 3 UI, spawns the sidecar, and owns tray + autostart. UI talks to the sidecar directly over REST + WebSocket.

**Tech Stack:** Python 3.12 (uv), FastAPI, uvicorn, faster-whisper (CPU int8), onnxruntime + Silero VAD ONNX, sounddevice, miniaudio, pycaw/comtypes, keyring, elevenlabs, edge-tts, claude-agent-sdk 0.2.152; Tauri 2.11 (Rust), Vue 3.5, Pinia, Vite, TypeScript.

Design reference: `docs/superpowers/specs/2026-09-07-sidekick-design.md`. Original spec: `rayban-companion-spec.md`.
